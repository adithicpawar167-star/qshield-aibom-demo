# qshield-aibom-demo

A synthetic fixture repository used to demonstrate QShield's AI-BOM
(AI Bill of Materials) assembly. It is not a real model release.

It deliberately contains everything an AI-BOM looks for in one place:

- `requirements.txt` with pinned AI/ML libraries (older versions, so known
  advisories are returned)
- `config.json` describing the model architecture and version
- `MODEL_CARD.md` with licence, datasets, metrics, and intended use
- `LICENSE` (Apache-2.0)
- `model.safetensors` as a stand-in weight file

See `MODEL_CARD.md` for the model details.
